# Translations

Reprise uses [Fluent](https://projectfluent.org/) for UI strings. English strings compile into each crate, and other languages load from `.ftl` files at startup.

## Where strings live

| Kind | Path |
| --- | --- |
| Crate English strings | `crates/<crate>/locale/en.ftl` |
| Repo translation | `data/locale/<lang>/<domain>.ftl` |
| Installed translation | `/usr/share/reprise/locale/<lang>/<domain>.ftl` |
| User override | `~/.local/share/reprise/locale/<lang>/<domain>.ftl` |

`<domain>` matches the name passed to `reprisekit::strings!` (for example `reprisekit`, `repriseapp`, `reprisefs`, `notepad`, `about`). `<lang>` is a tag like `de`, `pt-BR` or `pt_BR`.

Reprise searches `$XDG_DATA_HOME/reprise/locale` (default `~/.local/share/reprise/locale`), then `reprise/locale` in each `$XDG_DATA_DIRS` entry (default `/usr/local/share:/usr/share`).

## How Reprise picks a language

Reprise checks `LANGUAGE` (colon-separated), then `LC_ALL`, `LC_MESSAGES` and `LANG`. `C` and `POSIX` select English and ignore `LANGUAGE`. `fluent-langneg` matches requested tags to installed locales (so `de_AT.UTF-8` finds `de`).

Each domain loads once on first use. Restart a program to pick up language changes.

## How fallback works

Lookups check user files before system files, negotiated languages in order, and finally compiled-in English. Missing or broken messages fall back to English. An unknown ID renders as the ID itself and logs a warning.

## Add a string

1. Add a kebab-case message to the crate's `locale/en.ftl`, grouped under `##` comments.
2. Call `tr!` with a literal ID and `name = value` arguments (`&str`, `String` or numbers):

   ```rust
   use reprisekit::tr;

   let title = tr!("window-title", name = name.as_str());
   ```

3. Reuse shared strings (`"ok"`, `"cancel"`, `"apply"`, `"close"`, `"yes"`, `"no"`) via `reprisekit::kit_tr!`.

A crate adding translations for the first time creates `locale/en.ftl` and adds `reprisekit::strings!("<domain>");` at its root.

### Access keys

Prefix the access-key letter with `&` (for example `menu-file = &File`). Translations keep one `&` per label and avoid duplicate letters within a menu (`crates/reprisekit/tests/access_keys.rs` checks shipped locales). Escape dynamic text like file names with `reprisekit::text::escape_mnemonic`.

### Numbers and plurals

Numbers format using `number-group-separator` and `number-decimal-separator` from `reprisekit.ftl`. Set fraction digits with `NUMBER()`:

```
size-gb = { NUMBER($gb, minimumFractionDigits: 1, maximumFractionDigits: 1) } GB
```

Pass ungrouped numbers (line numbers, resolutions) as strings (`line = n.to_string()`). Use Fluent CLDR plural selectors:

```
cpu-cores =
    { $count ->
        [one] { $count } core
       *[other] { $count } cores
    }
```

Fluent's Unicode isolation marks are disabled because the text renderer draws them.

## Add a language

1. Copy a crate's `locale/en.ftl` to `data/locale/<lang>/<domain>.ftl` and translate the strings you want.
2. Add `reprisekit.ftl` with at least the two number separators.
3. Add `Name[<lang>]=` and `Comment[<lang>]=` to `data/apps/*.desktop`.
4. Run `scripts/i18n-check` (fails on IDs missing from English).
5. Test locally by copying files to `~/.local/share/reprise/locale/<lang>/` and running with `LANGUAGE=<lang>`.

See `data/locale/de/` for a sample German Notepad translation.

## Run translation checks

`scripts/i18n-check` verifies every `tr!` and `kit_tr!` ID exists in English, flags unused English IDs and rejects unknown IDs in translations. `cargo test -p reprisekit` runs it (`tests/i18n.rs`).

Under `cfg(test)`, a crate's own domain always uses English.

## Translation coverage

Translated areas: `reprisekit` dialog buttons, edit menu, Find and Replace, file dialog, About boxes and end-session dialog, `repriseapp` About text, About Reprise, Notepad, Paint (except palette colour names), Calculator menus, Sticky Notes menus and delete prompt, and Character Map and Font Viewer titles.

Remaining work covers the rest of `reprisekit` controls, the small apps (Volume, Power, Sound, Polkit, Accounts, Terminal), the large apps (Explorer, Settings, Network, Printers, Bluetooth, Updates), the compositor (`src/*view.rs`), `reprisefs`, `reprise-portal` and reading localized `Name[xx]=` / `Comment[xx]=` from `.desktop` files.

Dates follow `LC_TIME` (`LC_ALL`, `LC_TIME`, then `LANG`): short dates use `%x`, long dates use `reprisefs`'s `long-date` pattern, and relative labels use `date-today` and `date-yesterday`. Menu accelerators (`Ctrl+N`), times beyond 12/24-hour format, config-supplied strings, right-to-left layouts and non-emoji text shaping are not yet localized.
