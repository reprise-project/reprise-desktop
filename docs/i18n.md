# Translations

Reprise uses [Fluent](https://projectfluent.org/) for UI strings. English strings compile into each crate, and other languages load from `.ftl` files at startup.

## Where strings live

| Kind | Path |
| --- | --- |
| Crate English strings | `crates/<crate>/locale/en.ftl` |
| Repo translation | `data/locale/<lang>/<domain>.ftl` |
| Installed translation | `/usr/share/reprise/locale/<lang>/<domain>.ftl` |
| User override | `~/.local/share/reprise/locale/<lang>/<domain>.ftl` |

`<domain>` matches the name passed to `reprisekit::strings!` (`reprisekit`, `repriseapp`, `reprisefs`, `repriseconf`, `reprise` for the compositor and `reprise-portal`'s `portal`, plus one per program: `about`, `accounts`, `bluetooth`, `calc`, `charmap`, `datetime`, `diskusage`, `drives`, `explorer`, `fonts`, `imageviewer`, `import`, `network`, `notepad`, `notes`, `paint`, `phone`, `polkit`, `power`, `printers`, `record`, `schedtasks`, `settings`, `sound`, `taskmgr`, `terminal`, `updates`, `volume`, `welcome`). `<lang>` is a tag like `de`, `pt-BR` or `pt_BR`.

Reprise searches `$REPRISE_LOCALE_DIR` when set, then `$XDG_DATA_HOME/reprise/locale` (default `~/.local/share/reprise/locale`), then `reprise/locale` in each `$XDG_DATA_DIRS` entry (default `/usr/local/share:/usr/share`).

## How Reprise picks a language

Reprise checks `LANGUAGE` (colon-separated), then `LC_ALL`, `LC_MESSAGES` and `LANG`. `C` and `POSIX` select English and ignore `LANGUAGE`. `fluent-langneg` matches requested tags to installed locales (so `de_AT.UTF-8` finds `de`).

Each domain loads once on first use. Restart a program to pick up language changes.

## Desktop entries

Programs' `.desktop` files carry their own translations. Reprise reads `Name`, `GenericName` and `Comment` in the UI language for the Start menu and its subtitles, the launcher, Quick Launch buttons and tips, Explorer's shortcuts and their Properties (Comment), web links and the Startup programs list.

Each language Reprise asks for (`LANGUAGE`'s list, then `LC_ALL`, `LC_MESSAGES` or `LANG`) is tried in turn, most specific key first, as the Desktop Entry spec orders them: `Name[lang_COUNTRY@MODIFIER]`, `Name[lang_COUNTRY]`, `Name[lang@MODIFIER]`, `Name[lang]`. The first language with a non-blank value wins. An English, `C` or `POSIX` locale without its own value stops there and takes the plain `Name`, as does running out of languages. A translation without the plain key is ignored.

Searching programs matches both the translated and the plain `Name`. Renaming a shortcut writes the plain `Name` and removes its translations; editing its Comment does the same for `Comment`.

## How fallback works

Lookups check user files before system files, negotiated languages in order, and finally compiled-in English. Missing or broken messages fall back to English. An unknown ID renders as the ID itself and logs a warning.

## Add a string

1. Add a kebab-case message to the crate's `locale/en.ftl`, grouped under `##` comments.
2. Call `tr!` with a literal ID and `name = value` arguments (`&str`, `String` or numbers):

   ```rust
   use reprisekit::tr;

   let title = tr!("window-title", name = name.as_str());
   ```

3. Reuse shared strings (`"ok"`, `"cancel"`, `"apply"`, `"close"`, `"yes"`, `"no"`) via `reprisekit::kit_tr!`.

A crate adding translations for the first time creates `locale/en.ftl` and adds `reprisekit::strings!("<domain>");` at its root.

### Access keys

Prefix the access-key letter with `&` (for example `menu-file = &File`). Translations keep one `&` per label and avoid duplicate letters within a menu (`crates/reprisekit/tests/access_keys.rs` checks shipped locales). Escape dynamic text like file names with `reprisekit::text::escape_mnemonic`.

### Key names

Code spells a chord in English (`"Ctrl+Shift+N"`, `"Del"`, `"Alt+F4"`): menu accelerators, `MenuItem::shortcut`, config keybinds and anything written to a file keep that spelling. `reprisekit::keycap::shown_chord` turns it into the shown text, reading the modifiers, the named keys (`Del`, `Enter`, `PgUp`, the arrows...) and the `+` between them from reprisekit's `key-*` messages. Letters, signs and F1-F24 show as written; the key caps `keycap::key_text` names (`Print`, `Caps Lock`, `Left Ctrl`, the common media and brightness keys) have messages too, and any other key shows as written. Menus draw their accelerator column through it, and the shortcut box, the key sheet and tooltips show chords through `hotkey::chord_text`, which calls it.

A sentence that names a key takes it as a variable: `tr!("welcome-ready-clipboard", keys = shown_chord("Super+V"))` with `{ $keys } brings back what you copied.` in the .ftl, so a translation moves the chord with its grammar. A single key or modifier (`shown_chord("Shift")`) works the same way.

### Numbers and plurals

Numbers format using `number-group-separator` and `number-decimal-separator` from `reprisekit.ftl`. Set fraction digits with `NUMBER()`:

```
size-gb = { NUMBER($gb, minimumFractionDigits: 1, maximumFractionDigits: 1) } GB
```

Pass ungrouped numbers (line numbers, resolutions) as strings (`line = n.to_string()`). Use Fluent CLDR plural selectors:

```
cpu-cores =
    { $count ->
        [one] { $count } core
       *[other] { $count } cores
    }
```

Fluent's Unicode isolation marks are disabled because the text renderer draws them.

## Add a language

1. Copy a crate's `locale/en.ftl` to `data/locale/<lang>/<domain>.ftl` and translate the strings you want.
2. Add `reprisekit.ftl` with at least the two number separators.
3. Add `Name[<lang>]=` and `Comment[<lang>]=` to `data/apps/*.desktop`.
4. Run `scripts/i18n-check` (fails on IDs missing from English).
5. Test locally by copying files to `~/.local/share/reprise/locale/<lang>/` and running with `LANGUAGE=<lang>`.

See `data/locale/de/` for a sample German Notepad translation.

## Run translation checks

`scripts/i18n-check` verifies every `tr!` and `kit_tr!` ID exists in English, flags unused English IDs and rejects unknown IDs in translations. `cargo test -p reprisekit` runs it (`tests/i18n.rs`).

`scripts/pseudo-locale` checks that translated text fits (next section).

Under `cfg(test)`, a crate's own domain uses English unless `REPRISE_TEST_LOCALE=1` is set.

## Checking a translation's fit

`scripts/pseudo-locale` writes a pseudo translation, `en-XA`, of every domain to `tmp/pseudo-locale/locale/`: each message accented, about 35% longer and wrapped in `⟦ ⟧`, with placeables, selectors, access keys and strftime fields kept. It renders the gallery and the ignored preview tests under it, the same renders `scripts/pixels-unchanged.sh` compares, and writes `tmp/pseudo-locale/report.md`. The report lists per crate the English still drawn from code instead of an `.ftl` file, and each pseudo string that was ellipsized, drawn past its rect or lost its end marker. The PNGs land in `tmp/pseudo-locale/png/`. It takes as long as a full preview render and is not run in CI. `--report-only` rewrites the report from the last run's logs.

## Translation coverage

Every program, the compositor, `reprisefs`, `repriseconf`, `reprise-portal` and reprisekit's controls draw their UI text from a `locale/en.ftl`. That covers menus, dialogs, labels, tooltips, status text, notifications, access keys, accelerator and key names (including keys named inside sentences), numbers and plurals.

Still English:

- Config values and keys, and anything written to a file: they are data, not text.
- Protocol and D-Bus strings, command names and arguments, and device or service names that a program reads back.
- Log and debug output.
- The login service (`crates/repriselogin`, `crates/apps/login`).
- The text of `reprisekit`'s `addfinger` control, which still draws inline English.
- Text that comes from outside Reprise: file names, package descriptions, names reported by hardware, and strings from other programs.

`scripts/pseudo-locale` lists the English still drawn from code in each crate (see above). To find a string by hand, search non-test code for a string literal that reaches the screen and has no `tr!` or `kit_tr!` call.

Dates follow `LC_TIME` (`LC_ALL`, `LC_TIME`, then `LANG`): short dates use `%x`, long dates use `reprisefs`'s `long-date` pattern, and relative labels use `date-today` and `date-yesterday`. Times beyond 12/24-hour format, config-supplied strings, right-to-left layouts and non-emoji text shaping are not yet localized. Right-to-left layout is a later phase.
