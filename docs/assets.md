# Assets

Nearly everything on screen comes from code in this repository or software already installed on your system. System assets keep their own licenses.

## Built into this repository

These files share Reprise's GPL-3.0-or-later license:

- Controls and chrome drawn in code at output scale from shapes (`crates/reprisekit/src/shape/`), Blue's ten schemes (`crates/reprisekit/src/blue/scheme/`) and `[glass]` settings, plus generated GTK and Qt themes.
- Small icon PNGs in `crates/reprisekit/src/art/icons/` (loaded via `art::icons`) for tray status, Bluetooth devices, printer badges and Explorer overlays.
- Reprise logo, app icons (`data/icons/hicolor/`), masks (`crates/reprisekit/src/art/logo/`) and lockups (`docs/logo/`), built by `scripts/logo/build.py`. Lockups embed Adwaita Sans outlines under the SIL Open Font License.
- Screenshots in `docs/screenshots/`.
- Wayland protocol specs: `protocols/reprise-input-v1.xml`, `protocols/reprise-tabs-v1.xml`, `protocols/reprise-on-top-v1.xml`, `protocols/reprise-reopen-v1.xml`, `protocols/reprise-caption-v1.xml` and `protocols/reprise-output-trial-v1.xml`.

## Fonts

Reprise resolves `[fonts] family` through fontconfig in order (default `["Tahoma", "DejaVu Sans"]`). Bundled programs follow family and `antialias` changes live at 11 px, scaled by `[accessibility] text_size`.

| Font | Used for | Fallback | License |
| --- | --- | --- | --- |
| DejaVu Sans | General fallback | None | Bitstream Vera / public domain (`ttf-dejavu`) |
| Tahoma | UI text | DejaVu Sans | Wine version: LGPL-2.1-or-later (`ttf-tahoma`) |
| `[fonts] shell_dlg` | Wide dialogs (e.g. Power Options, Volume Control) | `[fonts] family` | Proprietary |
| Trebuchet MS | Blue window titles | DejaVu Sans | Proprietary |
| Franklin Gothic Medium | Blue Start label and Log Off / Turn Off titles | Trebuchet MS, DejaVu Sans | Proprietary |
| Segoe UI | Glass window titles | Noto Sans, DejaVu Sans | Proprietary |

Reprise does not ship or link to proprietary fonts. If you hold a license, copy the `.ttf` files into `~/.local/share/fonts`.

## Icons

Reprise loads application and desktop icons by freedesktop name from `[icons] theme` (default `hicolor`). Each icon theme keeps its own license.

Set `[icons] theme` to a directory name under `/usr/share/icons` or `~/.local/share/icons`, or choose it on the Fonts & Icons page. `hicolor` has very few icons, so install a complete theme. Early-2000s-style themes (32 px desktop, 16 px menu) match best, while Adwaita, Breeze and Papirus cover nearly every requested name.

Themes with an `icon-theme.cache` start faster. Run `gtk-update-icon-cache ~/.local/share/icons/<theme>` for manually installed themes. Reprise reloads icons automatically when files change. Missing icons fall back to a generic glyph, or a magenta square with a black border where no fallback exists yet.

## Colour schemes

The dark Classic schemes adapt palettes from [Ayu](https://github.com/ayu-theme/ayu-colors), [Catppuccin](https://catppuccin.com) (Mocha), [Dracula](https://draculatheme.com), [GitHub Dark](https://github.com/primer/github-vscode-theme), [Gruvbox](https://github.com/morhetz/gruvbox), Monokai (Wimer Hazenberg), [Night Owl](https://github.com/sdras/night-owl-vscode-theme), [Nord](https://www.nordtheme.com), [One Dark](https://github.com/atom/one-dark-syntax) and [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme). `scripts/dark-schemes.py` maps them to Reprise system colours.

## Wallpapers and sounds

Built-in wallpapers (`tarn`, `ridges`, `terraces`, `caustic`, `reeded`, `panes`, `flow`, `fold`, `contour`) are generated in `crates/reprisekit/src/wallpapers/` under GPL-3.0-or-later. The Background page also lists images from `/usr/share/backgrounds`, `/usr/share/wallpapers` and your Pictures folder (excluding `Screenshots`), and Browse... opens any `bmp`, `jpg`, `png`, `dib`, `jxl` or `avif` file.

Reprise ships no audio files. Desktop sounds play from your XDG sound theme (Settings > Sound).

## Contribute assets

New assets must have a GPL-3.0-compatible license and a source entry in this file. Do not contribute copied or traced artwork, sounds or fonts from other desktops or operating systems.
